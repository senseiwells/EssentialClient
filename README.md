EssentialClient is a client-side mod that adds many client utilities as well as
providing a gui to modify carpet rules!

## Usage

This mod requires the fabric-launcher, fabric-api, fabric-kotlin, and
[YetAnotherConfigLib](https://modrinth.com/mod/yacl).

Optionally, you can install [fabric-carpet](https://modrinth.com/mod/carpet),
[mod-menu](https://modrinth.com/mod/modmenu), [ChunkDebug](https://modrinth.com/mod/chunk-debug),
and [Kursive](https://modrinth.com/mod/kursive).

Once installed, you can access the EssentialClient menu through mod-menu, or by
pressing the EssentialClient Menu keybind, which is `F7` by default and can be
changed in options.

From this menu you can:
- View and modify the EssentialClient settings.
- View and modify the Carpet server settings.
- Open the ChunkDebug map, provided you have ChunkDebug installed and are connected to a server which supports ChunkDebug.
- Open the Kursive scripting menu, provided you have Kursive installed.

EssentialClient's settings are saved to `./config/EssentialClient/config.json`.

## Carpet Client

EssentialClient lets you view and modify [carpet](https://github.com/gnembon/fabric-carpet)
rules through a gui instead of having to use the `/carpet` command.

You do not need to have carpet installed on your client for this to work. 
Opening the Carpet Server Settings menu will show you every rule, sorted by category,
with the rule's description and its extra info. Rules from carpet
extensions (such as carpet-extra or carpet-fixes) are also shown, separated by mod.

You must have permission to modify carpet rules on the server for your changes to
apply, otherwise the rules will just be displayed to you.

![Carpet rules gui](docs/carpet-client.png)

To get rule descriptions when playing on a server, EssentialClient downloads a rule
database which is cached in `./config/EssentialClient/carpet_rules.json`. A massive
thank you to RubixDev for creating his [carpet database](https://github.com/RubixDev/carpet-database)
which EssentialClient pulls from.

## Separate Mods

ChunkDebug and Kursive used to be features of EssentialClient but have since been
split into their own mods. You can still access both of them from the EssentialClient
menu, but they must be installed separately:

- [ChunkDebug](https://modrinth.com/mod/chunk-debug) lets you view the chunk loading
  status of all the chunks in a world, this requires the mod to be installed on the
  server as well.
- [Kursive](https://modrinth.com/mod/kursive) is the successor to EssentialClient's
  client-side scripting, letting you write and run scripts on your client.

If either mod is not installed then its button in the EssentialClient menu will be
disabled.

## Settings

All the settings below can be found in the EssentialClient settings menu, they are
split into the same categories that you will find in game.

### Gameplay

| Setting                              | Description                                                                                                                                                                                                          |
|--------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Auto Walk                            | <p> This will hold your forward key after you have held it for the set amount of ticks </p>                                                                                                                           |
| Better Accurate Block Placement      | <p> This is the same as accurate block placement for tweakeroo but without the need for any server-side mods </p> <p> This uses some packet hacking, which may flag anti-cheat on some servers </p>                    |
| Crafting Hax                         | <p> Allows you to drop crafted recipes by holding control when crafting a recipe </p>                                                                                                                                 |
| Sneak To Not Waterlog                | <p> Allows you to sneak when using a bucket on a waterloggable block to avoid waterlogging </p>                                                                                                                       |
| Increase Spectator Scroll Speed      | <p> Increases the limit at which you can scroll to go faster in spectator </p>                                                                                                                                        |
| Increase Spectator Scroll Sensitivity| <p> Increases the sensitivity at which you can scroll to go faster in spectator </p>                                                                                                                                  |
| Tick Rate Affects Chat Key           | <p> Whether the tick rate affects your chat key, when true, with a lower tick rate it will take longer to open chat (vanilla behaviour) </p>                                                                          |
| Fix MacOS Cursor Jumping             | <p> Fixes the position of where the cursor jumps in text boxes when holding command or option to be consistent with MacOS </p>                                                                                        |
| Ignore Invalid Chat Messages         | <p> Ignores invalid chat messages and outputs them as system messages instead </p>                                                                                                                                    |

### Technical

| Setting                  | Description                                                                                                             |
|--------------------------|-------------------------------------------------------------------------------------------------------------------------|
| Announce AFK             | <p> This announces when you become AFK after a set amount of time (in ticks) </p>                                       |
| Announce AFK Message     | <p> This is the message you announce after you are AFK </p> <p> Requires 'Announce AFK' to be enabled </p>               |
| Announce Back Message    | <p> This is the message you announce after you are back from being AFK </p> <p> Requires 'Announce AFK' to be enabled </p> |
| Carpet Always Set Default| <p> This makes it so whenever you set a carpet rule, it automatically sets it to default </p>                            |
| Creative Walk Speed      | <p> This allows you to override the vanilla walk speed in creative mode </p>                                            |
| Custom Time Out          | <p> This lets you change the amount of seconds until you timeout when connected to a server </p>                        |
| Disable Hotbar Scrolling | <p> Prevents you from scrolling to use your hotbar, learn your keybinds! </p>                                           |

| Disable Night Vision Flashing  | <p> Disables the flash that occurs when night vision is about to run out </p>                          |
| Disable Recipe Toasts          | <p> Disables the recipe toast notifications from showing </p>                                          |
| Disable Advancement Toasts     | <p> Disables the advancement toast notifications from showing </p>                                     |
| Disable Tutorial Toasts        | <p> Disables the tutorial toast notifications from showing </p>                                        |

| Disable Screenshot Messages    | <p> Removes the message that pops up when you take a screenshot </p>                                   |
| Display Play Time              | <p> Displays the amount of time your client has been running in the corner of the pause menu </p>      |
| EssentialClient Button         | <p> This renders the EssentialClient Menu on the main menu screen and pause screen </p>                |
